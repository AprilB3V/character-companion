# Probably Stolen（深空当铺）游戏要点

> 版本：corpus v1（2026-11-04）。给伴侣角色当“老住户常识”用，也给人类读者快速了解游戏。
> 来源分三类，每条后面标注：**[公开]** Steam 页面与发行商公开信息；**[分析]** 本地程序静态分析，未在游戏内逐条验证；**[实况]** 2026-11 一季实况录播中的实际观察，单次样本，随难度、版本、市场事件变化。
> 不收录：游戏原文台词与字符串表、解包素材、配方与制法、主线剧情细节。

## 基础玩法

- 赛博朋克开店模拟。主角是一贫如洗的前拾荒者，在一座贫富分层的太空站下层区开了一间小店，背后有一位神秘导师。[公开]
- 核心循环：收货（NPC 上门卖货、批发、进货渠道名片）→ 鉴定真伪与品质 → 定价上架 → 卖给上门客人。玩家自己的总结是“低买高卖”。[公开][实况]
- 房租会持续上涨，长期目标是在被房租压垮之前攒钱买下店铺。[公开] 实况里房租先后见过 220、266 两档。[实况]
- 货的来路大多可疑，游戏名就是站上的生存法则：利润好看，东西八成是偷来的。赝品、管制品、赃物都会出现。[公开][实况]
- 开局可以拾荒，用工具箱拆杂物堆得到废金属、线缆、电子元件等基础物资，卖掉换第一笔钱。[实况]
- 难度影响明显：普通开局送放大镜，高难度开局没有；困难模式治安盘查更严。[分析][实况]

## 派系与声望

八个派系各算各的声望，讨好一边可能得罪另一边；举报会让相关声望下降。[分析][实况]

| 派系 | 说明 |
| --- | --- |
| 下层居民 | 店所在的下层区。声望够了会得到“恩惠”代币，用来向下层区领头人王尔德购买升级。 |
| 上层居民 | 上层区，客人更有钱，也会带着扫描仪来验货。 |
| 治安部 | 查店、罚款、追查赃物。声望低时日子难过。 |
| 黑市 | 地下交易势力。 |
| 革命派 | 政治势力，有专门的来客和事件（剧情向）。 |
| 游客 | 外来客群。 |
| 教会 | 独立派系，有专门角色和事件（剧情向）。 |
| 卡特尔 | 涉及特殊来客和交易的组织（剧情向）。 |

站上还有失控的 AI，会控制人，被控制的人只能除掉。[公开]

## 关键机制

- **犯罪值与调查进度**：两套独立数据。犯罪会累积当前犯罪值，同时推高调查进度；进度高了治安官会上门查店。调查进度低于 80 时犯罪值会自然消退，过了 80 就不会。[分析]
- **清除证据**：把调查进度和案件状态归零，但不清犯罪值；初始 500，每用一次加价 100，冷却 14 天。[分析]
- **掮客**：解锁并启用后按等级在夜间降低各类犯罪值，不降调查进度。[分析]
- **治安官到店**：会重新核对调查进度和犯罪总值；销赃被查会罚款并掉声望。实况中也出现过直接给治安官塞钱的处理方式。[分析][实况]
- **保险与失窃**：没买保险时，隔夜有概率被偷，值钱货、啤酒、矿石、枪都丢过；买了保险可防。[实况]
- **鉴定**：放大镜检查，配合鉴定指南和证书；拿到高级证书后可以给客人做鉴定、收鉴定费。创意工坊“鉴定助手”模组是另一回事，不能假定已启用。[分析][实况]
- **市场事件**：供水危机、日用品过剩、停电等词条会改变某类商品的供需。供水危机前囤水、停电时卖能量电池都是实况里赚到的操作。[实况]
- **电力与设备**：净水器、熔炉等设备耗电，需要能量电池；扩建机器区可提高容量。[实况]
- **进货渠道**：购买供货商名片后可打电话订货，次日送到（药商、酿酒厂、矿石等）。[实况]

## 常见梗（给角色吐槽用）

- “利润这么好看，八成是偷来的。”
- 调查进度逼近 80 时阴阳一句再提醒。
- 买“清除证据”：花钱洗白，洗的只是一半。
- 端水失败：一个派系声望涨、另一个跌。
- 同一样东西反复被偷（啤酒、矿石）。
