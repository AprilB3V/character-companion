数据来源：CL 版便携安装 `%LOCALAPPDATA%\CharacterCompanion\data\`（`game-events/`、`events/`、`proactive/`），时间范围 11-08 至 11-10。共 190 句鲸鲸台词。dsh 版会话在 `~/.dsh/sessions/--C-Program Files (x86)-Steam-...Probably Stolen--/`。下文时间都是北京时间。

## 0. 根因：读取模组和事件层没有“玩家在哪”这个概念

| 环节 | 现状 | 后果 |
|---|---|---|
| 读取模组 `snapshot.location` | 读的是 `PlayerStore.playerLocation`，游戏里这个枚举只有 `IN_STORE` 和 `INVENTOR` 两个值，只有进博士店（`DrJacksonLocation.Arrive`）时才会切换 | 去垃圾场拾荒、去小卖部、地图界面和模组新增的夜间地点，这个字段一直是 `IN_STORE`。也就是鱼主人说的“location 不跟着你出门” |
| 真正的外出状态 | 在 `MapUIManager.Instance.Current`（`AfterhourLocation`，Id 为 `dumping_ground` / `commissary` / `dr_jackson` / 模组地点），另有 `LastVisitedTonightId`、`TransitUI` 地图 | 模组完全没读 |
| 拾荒过程 | `ScavHelper.ScavengeDumpingGrounds()`：剩余次数、受伤概率、捡到的东西进外出口袋 | 没有任何事件；外出口袋的变化只体现在库存快照里，事件层不会发出“捡到了什么” |
| 夜间商店（博士店、酿酒拓展的四十七酿酒商店） | 店主是用交易面板实现的，游戏里算作 `currentClientInstance` | `game-world.mjs:368` 一律发 `npc_arrived:<id>`，`describe.ts` 写成“来客 X 到店”，所以鲸鲸以为对方来了店里 |
| CL 端 `location` | 只作为一个标量 fact 写入，没有任何地方使用；也没有打烊、外出、回店或换天的事件 | 鲸鲸无法区分白天和晚上，也不知道在店里还是出门 |

## 2. 拾荒完全不可见

- 190 句台词里，提到“拾荒”或“捡”的全都指来店里的**拾荒客**（访客 `scavGeneral`、`scavAppraisalRandom` 等），没有一句是关于玩家自己出门拾荒的。例：11-08 20:57 “我看他就是捡了堆水回来，还自称最伟大的拾荒者。”
- dsh 版会话的 `game_status` 返回值里，`location` 一直是 `"IN_STORE"`。

## 4. 顺带发现（优先级低）

- 11-08 20:03:30 同一秒里涌进 3 位来客（乔治奥、伦警官、杰克逊博士）的全部台词和成交记录，疑似读取延迟后一次性补发。鲸鲸把它们并成一句话评论。
- 来客每成交一件货就重复一次“好，听起来正合适。”，鲸鲸吐槽成“同一句话录了四遍，这拾荒客是复读机还是账本卡了”（11-08 20:54）。可能是游戏本身的行为，事件层可以合并。
- 思考理由里经常出现“我对当铺和药价一无所知，没有依据开口”。“不懂这家店”的立场让她在有话可说的时候也保持沉默。

## 5. 改造方向（待你补充后再定）

1. 读取模组：新增 `scene` 字段（`store` / `map` / `dumping_ground` / `commissary` / `dr_jackson` / 模组地点 Id），读 `MapUIManager.Current.Id`；挂钩 `ScavengeDumpingGrounds`，记录拾荒结果（捡到的物品、受伤、剩余次数）；增加打烊、出门、回店、换天事件。
2. 事件层：处在夜间地点时，`npc_arrived` 改写成“你走进了 X 的店”，并且不再按“来客”计数；同一晚第 N 次进同一个地点时，标注为“又逛回来”。
3. 知识库和人设：删掉“报价、压价、议价台”，改写成实际的玩法（批发收购、上架卖出、生产后出售）；降低房租和利润钩子的权重；去掉“还价”关键词。
