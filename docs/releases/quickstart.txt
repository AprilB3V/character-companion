Character Companion 0.1.0-rc.4 | Windows x64 | 文字版候选包

1. 把整个文件夹解压到可写目录，避免直接在压缩包里运行。
2. 双击 Configure.cmd，浏览器会打开本机设置页。
   选择模型服务商，填入 API Key、接口地址和模型名，点“测试连接”和“保存”，
   再点“启动 / 重新加载”。不需要手动编辑配置文件。
   Configure.cmd 不见了也没关系：直接双击 CharacterCompanion.cmd，配置不完整时会自动打开设置页；
   鲸鲸运行时也可以在托盘菜单里选“模型 / API 设置…”。
   正常启动需要填写模型配置。离线测试可运行 CharacterCompanion.cmd -Demo，
   浮窗会显示“离线演示 · 固定台词”，该模式用于检查界面。
3. 双击 CharacterCompanion.cmd，等待浮窗出现。在面板下方输入文字。
   修改模型配置后再次启动，会重新加载自己的后台服务。
4. 订阅并在游戏内启用 Jingjing World Bridge。
   https://steamcommunity.com/sharedfiles/filedetails/?id=3835039157
   载入存档后，鲸鲸会读取资金、库存及游戏事件。
5. 退出时双击 Stop.cmd。

便携包包含运行环境。默认使用文字输入。
设置、聊天记录和日志存放在 %LOCALAPPDATA%\CharacterCompanion。
模型请求会把对话及相关游戏信息发送给你选择的模型服务商，并可能产生费用。
请自行遵守模型服务商的使用条款。

排查问题
  日志目录    %LOCALAPPDATA%\CharacterCompanion\logs
  服务状态    http://127.0.0.1:8790/api/status
  游戏快照    http://127.0.0.1:8790/api/game/state
  端口被占用  停止原有伴侣后重试，保留日志便于排查。
  没有游戏数据  检查工坊下载、游戏内启用、重启及存档是否载入。
  配置被删或改坏  重新打开设置页保存即可重建；旧文件备份为 .env.video.local.bak。
  程序文件被删  重新运行安装器，会自动替换损坏的安装目录，设置与记忆不受影响。

更新时先停止运行，完整解压新版本后再启动。本机配置与记忆保存在用户目录。
需要清除个人记录时，退出后自行备份并删除上述用户目录。

dsh 版（已在用 DeepSeek Harness 的玩家）
  不需要上面的第 2、3 步。在本文件夹打开 dsh，对它说：“我想要这个仓库的dsh版”，
  它会按 AGENTS.md 自动安装。也可以手动双击 dsh-plugin\install.cmd。
  装好后关掉当前 dsh，双击 dsh-plugin\start.cmd，在 Web 界面里说“开始陪玩”。
  dsh 版和上面的 CharacterCompanion.cmd 二选一运行，两者都会占用浮窗端口。
