# Character Companion v0.1.0-rc.2

修复多个表情中新旧眉毛叠加的问题，并将此前保存在旧浮窗目录的修正版同步到正式素材和便携包。
覆盖 serious、stubborn、smug 的开口和闭口共六帧。修复仅在旧眉区域替换像素，
立绘轮廓、身体位置和嘴型保持一致。

Windows x64 文字版，包含运行环境、CharacterLife 内核和鲸鲸浮窗。
下载 `CharacterCompanion-0.1.0-rc.2-win-x64.zip` 后完整解压。
双击 `Configure.cmd` 配置模型，`CharacterCompanion.cmd` 启动，`Stop.cmd` 停止。

旧版本升级时先停止伴侣，完整解压新包再启动。
配置和记忆保存在 `%LOCALAPPDATA%\CharacterCompanion`，两个版本共用该用户目录。

游戏接口使用 [Jingjing World Bridge](https://steamcommunity.com/sharedfiles/filedetails/?id=3835039157)。
本次更新修改桌宠图片和素材构建步骤，游戏 Mod 仍为 1.2.0。

附件 SHA256SUMS 提供完整包校验值，包内 release-manifest.json 提供源代码版本和逐文件校验值。
回复验收使用模拟模型。用户配置的模型服务可能产生调用费用。
