# 公开发布准备

拟发布版本为 `v0.1.0-rc.1`，平台为 Windows x64，默认文字输入。
私测上传已由作者确认成功。工坊条目为 `3835039157`。
本机上传配置仍为私有可见。
作者已确认订阅、游戏内启用和存档载入后的游戏数据正确，并选择公开本源码仓库。

## 候选包

- 使用提交中的文件打包，排除工作区里未提交的内核修改。
- 包含便携 Node.js、Electron、适配层及内核，模型凭据由用户在本机配置。
- Node.js 下载核对官方 SHA-256，Electron 使用现有锁定版本。
- 包内保留第三方声明和运行时许可证，生成逐文件清单及 ZIP 校验文件。
- 作者于 2026-11-08 确认拥有内核及适配层版权，授权随安装包公开分发。

## 发布前验收

- [ ] 候选 ZIP 在独立目录解压、配置、启动、文字回复和停止通过。
- [ ] 重复配置保留现有用户凭据。
- [ ] 包内个人配置、数据库、日志和令牌检查通过。
- [ ] 独立审查安装入口及打包内容。
- [x] 私有工坊订阅后，在真实游戏内启用、载入存档并核对浮窗数据，作者确认。
- [ ] 以普通玩家权限确认 Release 附件可下载。
- [ ] 核对工坊页面和 Release 的双向链接。

## 公开时的操作

1. 作者已选择公开 character-companion。完成仓库公开检查后再切换可见性。
2. 选定验收过的提交，在 GitHub 创建预发布草稿并上传 ZIP、SHA256SUMS 和发布说明。
3. 下载草稿附件回验后，发布预发布版本。
4. 将工坊说明中的下载入口换成已可访问的发布链接，再将现有条目改为公开。

工坊更新始终沿用 `3835039157`，打包脚本已将它设为默认值。
新的上传配置放在 stage 的独立时间目录中，保留之前由 SteamCMD 更新过的配置。
公开版说明可使用 `-PublicListing` 生成，实际上传前需核对发布链接已可访问。
