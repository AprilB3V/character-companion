# Character Companion v0.1.0-rc.3

修复未配置模型时静默使用预设固定台词的问题。
正常启动现在要求真实模型配置，并核对内核绑定的是鲸鲸。
离线界面测试通过 `CharacterCompanion.cmd -Demo` 显式开启，浮窗会标明“离线演示 · 固定台词”。

## 本机设置页

首次使用双击 `Configure.cmd`，浏览器会打开本机设置页：选择 DeepSeek 官方或其他 OpenAI 兼容服务，
填写 API Key、接口地址和模型名（推荐 `deepseek-flash`，需要更强推理时可选 `deepseek-v4-pro`），
点“测试连接”“保存”，再点“启动 / 重新加载”。不再需要手动编辑配置文件。

- 配置不完整时直接双击 `CharacterCompanion.cmd` 也会打开设置页；鲸鲸运行时可在托盘菜单选择“模型 / API 设置…”。
- 配置文件被删、设置行被删、行前残留 `#`、内部令牌丢失时，设置页会提示并在保存时修复；每次保存前备份为 `.env.video.local.bak`。
- 设置页只监听 `127.0.0.1`，带一次性令牌；凭据只保存在本机。
- 程序文件被误删时重新运行安装器即可：损坏的安装目录会被改名保留并重新安装，设置与记忆不受影响。

再次启动 `CharacterCompanion.cmd` 会自动应用配置变化，重新加载已确认归属的鲸鲸后台服务。

## dsh 版

已在用 DeepSeek Harness（dsh）的玩家可以改用 dsh 版：在包目录打开 dsh，说“我想要这个仓库的dsh版”，
它会按 `AGENTS.md` 询问人设、称呼、话量和浮窗后自动安装；也可以双击 `dsh-plugin\install.cmd`。
dsh 版与 `CharacterCompanion.cmd` 二选一运行。

## 下载

Windows x64 便携包包含运行环境、CharacterLife 内核和六张眉毛修正版差分。
下载 `CharacterCompanion-0.1.0-rc.3-win-x64.zip` 后完整解压。
停止伴侣可双击 `Stop.cmd`。

游戏接口使用 [Jingjing World Bridge](https://steamcommunity.com/sharedfiles/filedetails/?id=3835039157)。
模型调用可能产生费用，相关对话及游戏信息会发送至用户配置的模型服务。
