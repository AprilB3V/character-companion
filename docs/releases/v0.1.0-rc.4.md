# Character Companion v0.1.0-rc.4

鲸鲸现在知道你人在哪、伤得怎样、捡到了什么。需要把读取模组 [Jingjing World Bridge](https://steamcommunity.com/sharedfiles/filedetails/?id=3835039157) 更新到 1.4.0（订阅后 Steam 会自动更新）。

## 代入感更新

- **位置**：能区分店里、夜里看地图、垃圾场、小卖部、博士店和模组新增的夜间地点。
    - 在一个地方停留满 5 秒才算到达，在地图上来回切换不会刷屏。
    - 出门、回店、第一次去某个地方时，她会开口一次。
    - 同一晚再去同一个地方，她不再当成新鲜事。
- **夜间商店**：博士店、四十七酿酒商店等地方，是你走进了对方的店，不再被说成“又有人来店里了”。
- **伤情**：她知道你是健康、轻伤还是重伤，伤情稳不稳定。受伤或伤势加重时她会关心一句。
- **拾荒**：拾荒的结果终于看得见了。捡到单件估值 50 以上的东西时她会开口；平常的收获只记下来，不打扰你。
- **议价**：打折、加价、勒索、威胁都会告诉她，包括对方接受了还是拒绝了。她不用再凭成交价去猜。
- **难度**：她读到的是游戏自己的规则说明，比如普通难度卖货加价 15%、挑战难度不加价，难度变化时也会知道。
- **晨报**：游戏早上那页“昨夜发生了什么”也会交给她。
- **来客**：
    - 多位来客的台词按到店顺序交给她，上一位说的话不会再算到下一位头上。
    - 来客的固定台词重复时会标出来，她不会再把它当成新信息。

## 兼容性

- 旧版桌宠配新模组：可以运行，只是读不到新信息。
- 新版桌宠配旧模组：可以运行，位置、伤情等信息为空。
- dsh 版的 `game_status` 也有位置、伤情和难度字段。

## 下载

Windows x64 便携包，包含运行环境和 CharacterLife 内核。下载 `CharacterCompanion-0.1.0-rc.4-win-x64.zip` 后完整解压。

- 第一次使用：双击 `Configure.cmd` 完成模型设置。
- 已经在用 rc.3：解压到新目录直接启动即可，设置和记忆都保存在用户数据目录，不受影响。
- 停止伴侣：双击 `Stop.cmd`。

模型调用可能产生费用，相关对话及游戏信息会发送至用户配置的模型服务。
