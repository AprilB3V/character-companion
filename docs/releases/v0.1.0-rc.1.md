# Character Companion v0.1.0-rc.1

Windows x64 文字版候选包，包含鲸鲸浮窗、CharacterLife 内核和运行环境。

下载附件 `CharacterCompanion-0.1.0-rc.1-win-x64.zip` 并完整解压。
首次使用双击 `Configure.cmd`，在本机配置模型。
双击 `CharacterCompanion.cmd` 启动，输入文字即可对话。
默认配置使用模拟回复，填写模型参数后使用所选模型服务。

游戏接口通过 [Jingjing World Bridge](https://steamcommunity.com/sharedfiles/filedetails/?id=3835039157) 提供。
订阅并在游戏内启用，按提示重启游戏，再载入存档。
该 Mod 只读取游戏数据，向本机文件输出快照。
当前游戏适配 Mod 版本为 1.2.0，声明支持 Probably Stolen `100-Rev6`。

便携包默认提供文字输入。模型调用可能产生费用，相关对话与游戏信息会发送给所配置的模型服务商。
配置和记忆保存在 `%LOCALAPPDATA%\CharacterCompanion`。
停止运行可双击 `Stop.cmd`。

SHA-256 校验值见附件 `SHA256SUMS.txt`。
组件版本、源代码提交和逐文件校验值见包内 `release-manifest.json`。

候选包验收和公开发布入口的检查进度见仓库 `docs/releases/readiness.md`。
