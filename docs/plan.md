## 鲸鲸整合包实现说明


### 目标与原则

玩家只做两件事就能和鲸鲸一起玩 Probably Stolen：在创意工坊订阅适配 mod，下载整合包并跑完首次向导。其余安装、配置、启动全部由启动器完成。

- **三层解耦**：CL 后端、桌宠浮窗、游戏适配 mod 互相独立，只通过本地连接约定通信。换游戏只需新写一个适配器，后端和桌宠不动。
- **浮窗保持独立**：已做好的浮窗不融入游戏、不重绘像素立绘，可单独作为桌宠使用，也供未来接口复用。
- **门槛优先**：默认路径不要求玩家装 Python、配环境或手动改文件；重依赖（语音模型）做成可选下载。
- **开发不被发版拖累**：后端与桌宠走启动器自更新，CL 的语义、剧本、记忆层迭代不必每次都改工坊 mod。

### 整体架构

CL 后端是唯一的中心：适配 mod 把游戏事件发给它，桌宠从它接收台词和表情，启动器负责把后端和桌宠拉起来并检查 mod。


mod 只依赖连接协议，不依赖后端实现；以后接新游戏，只需按同一协议再写一个适配器（虚线部分）。

### 整合包内容与目录结构

主包只含运行必需的部分，语音模型等大文件按需下载，主包体积尽量压小。

| 组件 | 是否在主包 | 说明 |
| --- | --- | --- |
| 启动器 | 是 | 唯一入口，负责向导、启停、更新、日志 |
| CL 后端 | 是 | 打包为免安装运行时（如 PyInstaller / 嵌入式 Python），玩家无需装环境 |
| 桌宠浮窗 | 是 | 现有浮窗原样打包，可脱离游戏单独运行 |
| 默认角色包（鲸鲸） | 是 | 语义、剧本、差分立绘、配置，与后端代码分开存放 |
| SenseVoice 语音模型 | 否，可选下载 | 用户选择语音输入时再下载 |
| 适配 mod | 否 | 走创意工坊订阅，启动器只负责检查与引导 |

建议目录：

```
CharacterCompanion/
  launcher.exe
  runtime/        # CL 后端运行时
  pet/            # 桌宠浮窗
  characters/
    jingjing/     # 角色包，与代码分离
  models/         # 可选下载的语音模型
  config/         # 用户配置（API key 等），更新时不覆盖
  logs/
```

角色包与代码分离，是为了以后做别的角色包、或单独发布桌宠时直接复用。`config/` 在任何更新中都不能被覆盖。

### 启动器功能清单

启动器是玩家唯一需要打开的程序，第一版只做下面这些，按优先级排列。

1. **首次运行向导**（见下一节）。
2. **一键启停**：启动 / 停止 CL 后端与桌宠，显示两者的运行状态。
3. **跟随游戏自动启动（可选开关）**：检测到 Probably Stolen 进程启动时自动拉起后端与桌宠，游戏退出后可选自动关闭。
4. **设置页**：LLM 提供方与 API key、输入方式（文字 / 语音）、麦克风选择、说话意愿等常用参数；随时可改，不必重跑向导。
5. **连接状态检查**：显示 mod 是否已连上后端，连不上时给出原因（游戏未启动、mod 未激活、端口被占用）。
6. **更新检查**：启动时检查后端、桌宠、角色包是否有新版本，一键更新，不覆盖 `config/`。
7. **日志与反馈**：一键打开日志目录，一键打包日志（自动剔除 API key）方便玩家反馈问题。

第一版不做：账号系统、内置商店、多角色切换界面。

### 首次运行向导流程

向导共五步，每步都可返回，任何一步失败都要给出下一步该做什么，而不是只报错。

1. **检测游戏**：自动查找 Probably Stolen 安装位置（读取 Steam 库配置）；找不到时允许手动选择目录。
2. **检查适配 mod**：检查 mod 是否已订阅并出现在游戏 Mods 目录。未订阅 → 按钮直接打开工坊页面（`steam://` 链接）；已订阅 → 提示在游戏内 Modding 窗口激活并重启游戏。
3. **配置 LLM**：选择 API 提供方并填写 key，或选本地模型；填完立即发一条测试请求，成功才进入下一步。附图文说明链接。
4. **选择输入方式**：默认文字输入；选择语音输入时下载 SenseVoice 模型（显示大小与进度），并做一次麦克风试录。
5. **试运行**：启动后端与桌宠，让鲸鲸说一句开场白，确认桌宠显示正常；提示"进入游戏后鲸鲸会自动连上"。

完成后写入 `config/`，下次打开启动器直接进入主界面。

### mod 与后端、桌宠的连接约定

以下为建议方案，CC 实现前可按现有代码调整，但需保持"后端是中心、mod 和桌宠都是客户端"这一结构。

- **传输**：后端在 `127.0.0.1` 上开本地 WebSocket，只监听本机。默认端口固定，被占用时自动换端口。
- **端口发现**：后端启动后把实际端口写入用户目录下的固定文件（如 `%APPDATA%/CharacterCompanion/endpoint.json`），mod 与桌宠读取它连接；读不到时回退默认端口。
- **消息格式**：JSON，每条带 `type` 与 `protocol` 版本号。握手时双方交换版本，不兼容时 mod 在游戏内提示"请更新整合包"。
- **mod → 后端**：握手、心跳，以及游戏事件——NPC 对话文本、NPC 行为、信用点变动、当前场景 / 营业状态。
- **后端 → mod**：第一版只发"鲸鲸正在说话"状态，供游戏内显示一个小提示；指令类消息留到以后。
- **后端 ↔ 桌宠**：沿用现有通道，内容为台词、表情差分、说话状态。
- **断线处理**：mod 连不上时每隔几秒重试，并在游戏内提示一次"请先打开鲸鲸启动器"，不刷屏。

协议文档单独存放在仓库中，以后给其他游戏写适配器时照此实现即可。

### 分发与更新

工坊页面是入口，整合包从工坊页链接下载；两条下载渠道并行，照顾国内访问。

| 内容 | 渠道 | 更新方式 |
| --- | --- | --- |
| 适配 mod | Steam 创意工坊 | Steam 自动更新 |
| 整合包（首次安装） | GitHub Releases + 国内网盘 / 镜像 | 手动下载一次 |
| 后端、桌宠、角色包 | 启动器自更新，源同上 | 启动器提示后一键更新 |
| 语音模型 | 同上 | 版本变化时才重新下载 |

- 工坊页面写清楚"两步上手"，整合包下载链接放在最显眼的位置，B站 / 抖音视频简介同步放链接。
- 每个版本附简短更新说明，启动器内可查看。
- 整合包与 mod 的协议版本号一起发布，避免玩家只更新了其中一边。

### 分阶段计划与验收标准

分三阶段推进，每阶段验收通过再进入下一阶段。

**阶段一：协议与适配 mod**

- [ ] 后端开出本地 WebSocket，端口发现文件可用
- [ ] mod 能握手、发送 NPC 对话 / 行为 / 信用点事件，断线后自动重连
- [ ] 游戏内能显示"鲸鲸正在说话"的小提示

**阶段二：整合包与启动器**

- [ ] 后端与桌宠打包为免安装运行时，在一台没装过开发环境的电脑上能直接运行
- [ ] 首次向导五步全部可用，LLM 测试请求、mod 检查、语音模型下载都有失败提示
- [ ] 一键启停、跟随游戏自动启动可用

**阶段三：发布与更新**

- [ ] 启动器自更新可用，更新后 `config/` 不被覆盖
- [ ] 日志一键打包且不含 API key
- [ ] 工坊页面、GitHub Releases、国内镜像同步上线

**总验收**：找一位没接触过项目的人，只看工坊页面，能在 15 分钟内让鲸鲸在游戏里说出第一句话。
